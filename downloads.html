Thessley Security Hardening for WordPress

Version 1.0.23 · ZIP package

Modular security features for WordPress. This project build is distributed for evaluation; install it on a staging site first and keep a site backup.

Download plugin ZIP SHA-256 checksums

Install the WordPress plugin

  1. Back up the site, then download the ZIP and verify its SHA-256 hash using the checksum file.
  2. In WordPress admin, open Plugins → Add Plugin → Upload Plugin.
  3. Select the ZIP, install it, and activate Thessley Security Hardening.
  4. Review the plugin dashboard and event log. Leave modules in log-only mode while confirming the events are correct.
  5. Test any enforcement setting on staging first. Keep a working administrator session and recovery path.

Android Passkey app

Version 0.1.18 · Android APK

Android companion app for Thessley phone approvals. Package: com.eagleeyeintelligence.thessleypasskey. Requires Android 8.0 or later.

Download Android APK SHA-256 checksums

Install the APK only if Android accepts its signature for your current installation. If Android reports a signature conflict, keep your installed copy and use the matching Play release when available. Do not uninstall an enrolled app to work around a signature conflict: uninstalling deletes its phone keys.
