Phone approvals

Thessley Passkey

Approve compatible sign-in requests from websites and computers with your phone. The Android app supports QR codes and approval links, with biometric confirmation for signing requests.

Android availability: version 0.1.11 is available as a direct APK download. Google Play testing remains a separate distribution route.

Computer access

SSH, desktop and VPN approvals

Companion tools add phone approval to supported SSH and computer sign-in flows. Windows packages include the approval service, a local HTTPS admin page, and setup guides.

The Ubuntu OpenVPN integration checks a separate client certificate and then requests a time-limited Thessley QR approval for every connection and reconnect.

For Ubuntu 24.04, install the signed Linux package from the APT repository hosted on the Orange Pi 5, or download the source archive. Windows packages are also available, with installation guidance and checksums.

WordPress

Thessley Security Hardening

A modular WordPress plugin for request filtering, login protection, file and account monitoring, security headers, vulnerability checks, and event reporting.

Drupal

Thessley Passkey for Drupal

QR or one-tap sign-in for Drupal's /user/login, with optional, password-then-app, or app-only modes. The same Thessley Passkey app works with WordPress and Drupal.

Requires Drupal 10.6+ or 11 and PHP 8.3+.

Use cases across your systems

Thessley covers WordPress security and phone-approved access for supported computers and VPNs. These are separate components with different requirements—start with one system, a limited pilot, and a verified recovery path.

Agencies

A repeatable site review

For agencies maintaining several WordPress sites, use one pilot site to review configuration, observe the event log, and document a safe rollout and rollback before deciding whether to standardize.
